# Расчёт успеваемости студентов

Браузерный учебный портал Международного колледжа бизнеса и коммуникаций (ICB) с кабинетом преподавателя и личным кабинетом студента. Интерфейс на русском языке, сборка и установка библиотек не нужны.

## Запуск

Откройте `index.html` в современном браузере. Для запуска тестов установите Node.js и выполните из папки проекта:

```powershell
node --test tests/student-manager.test.js
```

Данные хранятся в `localStorage` текущего браузера. При первом открытии загружается демонстрационная группа из семи студентов. Кнопка «Очистить данные» удаляет их после подтверждения.

Демонстрационный вход студента: логин `ICB001`, код `246810` (Арман). Другие демонстрационные логины: `ICB002`–`ICB007`; коды для них указаны в исходных данных `app.js`. При добавлении студента преподаватель получает новый логин и код прямо в уведомлении формы. Их также можно посмотреть, нажав на имя студента в ведомости.

Это локальный учебный прототип: аккаунты и изменения видны в том же браузере/профиле, где открыт портал. Для общей работы студентов с разных устройств потребуется серверная база данных и настоящая серверная авторизация; текущие коды доступа не предназначены для защиты реальных персональных данных.

## Возможности

- Добавление студента с оценками от 0 до 100 по шести предметам ICB. Можно указать один или несколько предметов.
- Просмотр оценок и результата сдачи предмета по нажатию на имя.
- Кабинеты преподавателя и студента; студент входит по логину и коду и видит только свои оценки.
- Шесть дисциплин ICB: высшая математика, веб-программирование, вайб-программирование, робототехника, мобильные приложения и базы данных.
- Изменение оценок в кабинете преподавателя; новые значения появляются в личной ведомости студента при следующем входе.
- Средний балл, уровень успеваемости, число сданных предметов, сортировка и поиск.
- Сводные показатели высокой успеваемости (средний балл от 90) и студентов, которым нужна поддержка (ниже 50).
- Аналитическая сводка со средним баллом группы и по каждому предмету; индикаторы обновляются при добавлении и удалении оценок.
- Фильтр по уровням успеваемости с количеством студентов в каждой категории.
- Фоновые видеообои Wavy Grass в беззвучном режиме с автоматическим повтором; интерфейс видеоплеера скрыт.
- Интерактивные состояния кнопок и поддержка системной настройки уменьшения анимации.
- Удаление отдельной записи, очистка ведомости и сохранение изменений в браузере.
- Проверка пустого имени, пустых оценок, дробных значений и выхода за диапазон.

## Основные функции

- `createStudent` проверяет имя и оценки, затем создаёт запись.
- `averageScore` рассчитывает среднее арифметическое оценок.
- `getPerformanceLevel` определяет уровень по среднему баллу.
- `hasPassed` проверяет, достигла ли оценка проходного значения 50.
- `sortByAverage`, `getHighPerformers`, `getStudentsNeedingSupport` и `removeStudent` работают со списком студентов.
- `render`, `renderStudentRow` и `showGrades` отвечают за отображение ведомости и подробностей.

### Найденные проблемы и рефакторинг

- Скрипт интерфейса был подключён дважды: обработчики могли срабатывать повторно. Оставлено одно подключение.
- Стили переопределяли атрибут `hidden`, поэтому пустое состояние могло отображаться поверх заполненной таблицы. Добавлено явное правило скрытия.
- Пробельная строка преобразовывалась в числовой ноль. Пустые строки и строки из пробелов теперь пропускаются, а форма требует хотя бы одну оценку.
- Проверка сохранённых в браузере записей принимала пустой список оценок. Добавлена валидация данных при чтении.
- Расчёт среднего повторялся в нескольких местах и подпись единиц измерения сливалась с числом. Среднее вычисляется один раз на строку, формат отображения исправлен.
- Логика проверок и расчётов вынесена в `student-manager.js`; оценки, пороги и предметы заданы константами. DOM-рендеринг остаётся в `app.js`.

Тесты предметной логики находятся в `tests/student-manager.test.js` и запускаются командой выше. В среде разработки Node.js отсутствует, поэтому команда `node --test` здесь недоступна; обязательные сценарии выше были фактически проверены через браузерную автоматизацию.

### Проверки кабинетов ICB

В браузере дополнительно проверены шесть предметов в форме, создание аккаунта, выдача логина и кода, успешный и неуспешный вход, отображение личных оценок, редактирование оценки преподавателем и её отображение после повторного входа студента. Все сценарии пройдены. Автозапуск фонового видео зависит от доступности Moewalls и политики браузера.
